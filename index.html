Snakes & Ladders

Find the fewest dice throws needed to travel from square 1 to square 100 using five informed and uninformed search algorithms, on the same board, with the same cost model, each one playing back independently.

1. Game Board

Place snakes and ladders; all five algorithms run on this same board.

Ladder (up)Snake (down)StartFinish
Game rules (as implemented):
  1. The game starts on square 1 and numbers zig-zag upward (first row left to right, next row right to left, …).
  2. Each throw is a die roll of 1–6 and the token advances that many squares; e.g. from 1 a 6 lands on 7, another 6 lands on 13.
  3. A throw that ends exactly on a ladder base climbs it (13 → 46); one that ends on a snake head slides down.
  4. To win, the token must land exactly on 100; a throw that would overshoot 100 is not allowed.

2. Algorithm Lab

Every search keeps choosing one thing: which square to check next.

In plain words: the goal is to reach square 100 with the fewest dice throws. Uninformed searches follow a fixed rule and have no idea where square 100 is. Informed searches also get a hint, an estimate of how many throws are left, so they head toward the goal and check far fewer squares.

5. Problem Formulation

Problem components in the intelligent-agent framework.

AgentThe player’s token
EnvironmentA 10×10 board with snakes and ladders
Initial stateSquare 1
Goal testLanding exactly on square 100 (throws that overshoot 100 are not allowed)
ActionsRoll a die (1–6); if the token lands on a snake head or ladder base it is moved
CostEvery throw costs 1 unit, so only the number of throws counts; it makes no difference whether you roll a 1 or a 6
HeuristicFewest throws in a relaxed problem that ignores the snakes’ penalty; admissible and consistent (used by Greedy and A*)
Environment assumptionDiscrete and fully observable; the die outcome is treated as choosable so the problem is deterministic and the answer is the fewest possible throws
